# 9 Requirements Traceability

## 9.1 Extended traceability matrix

This matrix uses the consolidated UC-01 through UC-04 list in [Section 3](https://github.com/azghier1/Ai-Agent/blob/867c8ed048061e2fb965d39340508cd57f025f03/docs/p2/sections/3-requirements.md) and the [expanded scenarios in Section 4](https://github.com/azghier1/Ai-Agent/blob/867c8ed048061e2fb965d39340508cd57f025f03/docs/p2/sections/4-use-cases.md). UC-05 is not retained as a separate goal; practice questions map to UC-04. Sources are pinned because PR #7 targets `docs/team-onboarding`, which does not yet contain these merged-main sections.

Component names and analysis concepts follow [Section 6.3 / 6.5](https://github.com/azghier1/Ai-Agent/blob/867c8ed048061e2fb965d39340508cd57f025f03/docs/p2/sections/6-design.md). `AssistantInterface` and `AssignmentOrganizer` are supported by Daniel's [UC-02 analysis draft](https://github.com/azghier1/Ai-Agent/blob/aa281384fcb3badbd0ce10782e55633d3d7b5216/docs/p2/sections/5-2-uc02.md) in PR #3. Other analysis names below are concepts from Section 6.5, not invented or approved domain classes. Final Section 5.1 and UC-01 object names were unavailable in the inspected branches and still need reconciliation. ADR references use Daniel's [Section 7 draft](https://github.com/azghier1/Ai-Agent/blob/0209b824ca2ea09bf75f56e3e236906fd6a53cf5/docs/p2/sections/7-rationale.md) in PR #2 and remain subject to its review.

“Partial” means relevant code exists, not that the acceptance test passed. “Unverified” means no acceptance evidence was available. Source inspection uses the unchanged `server.py`, `agent.py`, `lms.py` and `web/` in PR #7's original source commit `20f021f`.
